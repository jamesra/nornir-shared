# nornir-shared

Shared Python utilities for Nornir packages (logging helpers, plotting, filesystem, parallel helpers, and related tools).

- **Full manual and API (umbrella):** [https://nornir.github.io/](https://nornir.github.io/)

- **API reference:** [`nornir_shared` module](https://nornir.github.io/api/nornir_shared.html)

## Where user-facing documentation goes

User-facing documentation lives in the umbrella repository ([jamesra/nornir](https://github.com/jamesra/nornir)), not in this package:
